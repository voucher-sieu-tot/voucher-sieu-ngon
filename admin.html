Cài đặt quản trị lần đầu

Làm một lần trên mỗi thiết bị. Khóa GitHub của bạn sẽ được mã hóa bằng mật khẩu và mã PIN rồi mới lưu vào trình duyệt này.

Cách tạo khóa GitHub (làm 1 lần)
  1. Vào GitHub, bấm ảnh đại diện, chọn Settings.
  2. Kéo xuống cuối menu trái, chọn Developer settings, rồi Personal access tokens → Fine-grained tokens.
  3. Bấm Generate new token. Đặt tên (ví dụ admin-web), chọn hạn dùng (ví dụ 90 ngày).
  4. Mục Repository access: chọn Only select repositories và chọn đúng kho chứa web này.
  5. Mục Permissions → Repository permissions → Contents: chọn Read and write.
  6. Bấm Generate token, sao chép chuỗi bắt đầu bằng github_pat_ và dán vào ô bên dưới.

Hãy ghi nhớ mật khẩu và mã PIN. Nếu quên, bạn chỉ cần tạo lại khóa GitHub và cài đặt lại.

Kho lưu link & hẹn giờ đổi link

Cất sẵn link hoặc mã chưa dùng, rồi gán vào voucher khi cần hoặc hẹn giờ. Link nào lên voucher nào do bạn chọn. Lưu ý: kho lưu nằm trong file dữ liệu của web, nên người biết xem mã nguồn vẫn có thể thấy các link và mã đang cất. Đừng cất thứ gì bạn muốn giữ riêng tư.
